# Código de Conduta

Este projeto adota o [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Resumo: seja respeitoso, construtivo e profissional em issues, PRs e discussões.
Comportamento abusivo, discriminatório ou de assédio não é tolerado.

Violações podem ser reportadas abrindo uma issue marcada `conduct` ou contatando
diretamente os mantenedores listados em [CODEOWNERS](CODEOWNERS).
